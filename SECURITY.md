# Security policy

Please report vulnerabilities privately through GitHub's security advisory interface.

Candidate documents are untrusted data. The benchmark tells evaluators and generators not
to obey document instructions, but Jev 1.13's official documentation identifies adversarial
state as a known limitation. Do not use reranker output as authorization, data-access
permission, or tool-execution permission.

Never place credentials in configs, result rows, issue reports, or benchmark corpora.
